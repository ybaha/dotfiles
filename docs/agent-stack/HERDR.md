# Herdr → hc

The old `herdr` TUI CLI is no longer the active runtime. See [HC.md](HC.md) for terminal ownership, Ovis/herdr-app labels, the implemented command mapping, restart/worktree workflows and validation limits.

Use `hc --skill` for persistent terminals and `herdr-app --skill` for window arrangement. Do not install the old Pi integration or workflow plugins for hc. Legacy reporters are disabled; hc observes program status itself. Chief is disabled pending an hc port.
